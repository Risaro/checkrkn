# checkrkn

Защищает сервер от сканеров и атакующих: ГРЧЦ (СКИПА), Censys, Shodan, ботнеты, угнанные подсети. Плюс сам банит тех, кто сканирует порты сервера.

## Установка

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Risaro/checkrkn/main/checkrkn.sh)
```

Вопросов не задаёт. После установки список обновляется каждые 6 часов и применяется заново после перезагрузки.

## Команды

```bash
checkrkn status       # сколько адресов в блоке, сколько в автобане, сколько пакетов отброшено
checkrkn update       # обновить список сейчас
checkrkn unban 1.2.3.4
checkrkn uninstall
```

## Списки

Списки собираются автоматически каждые 6 часов (GitHub Actions) и лежат в репозитории:

| Файл | Что внутри |
|---|---|
| [`lists/blocklist.txt`](lists/blocklist.txt) | полный: всё из безопасного списка плюс активные атакующие |
| [`lists/blocklist-safe.txt`](lists/blocklist-safe.txt) | только сканеры и инфраструктура злоумышленников |
| [`lists/stats.json`](lists/stats.json) | сколько адресов дал каждый источник при последней сборке |

Источники безопасного списка: сканеры РКН/ГРЧЦ, исследовательские сканеры SANS ISC (Shodan, Censys и др., активные за последние 30 дней), Spamhaus DROP, DShield, Emerging Threats, abuse.ch Feodo.

Источники полного списка дополнительно: ipsum, CINS Army, BinaryDefense. Из них вырезаются все адреса России по реестру RIPE, потому что в таких списках много заражённых домашних устройств, а это могут быть ваши пользователи.

Никогда не блокируются: частные и служебные сети, Cloudflare, публичные DNS. Если источник недоступен, используется его последняя сохранённая версия.

Только безопасный список:

```bash
CHECKRKN_LIST=safe bash <(curl -Ls https://raw.githubusercontent.com/Risaro/checkrkn/main/checkrkn.sh)
```

## Автобан сканеров

Если адрес за короткое время стучится в несколько разных закрытых портов, он попадает в бан на 24 часа. Список открытых портов скрипт определяет сам раз в минуту (`ss` плюс проброшенные порты Docker), поэтому обычные клиенты, которые подключаются к вашим сервисам, под бан не попадают, даже если открывают сотни соединений.

Настройка при установке:

```bash
CHECKRKN_AUTOBAN=0          # выключить автобан
CHECKRKN_BAN_TIME=6h        # длительность бана
CHECKRKN_SCAN_PORTS=4       # порог: разных закрытых портов в минуту (сверх такого же запаса)
```

Дополнительные порты, которые нужно считать открытыми, впишите в `/etc/checkrkn/ports.txt` (порт или диапазон `1000-2000` на строку).

## Белый список

Адреса, которые нельзя блокировать ни при каких обстоятельствах (ваши серверы, мосты, панели), впишите в `/etc/checkrkn/allow.txt`, по одному IP или подсети на строку. На них не действуют ни списки, ни автобан. Если в скачанном списке окажется такой адрес, список не применится, и останется последний рабочий.

## Чем отличается от обычных скриптов-блокировщиков

- Своя таблица nftables. UFW, iptables-persistent и правила Docker не трогает, безопасно на нодах с Docker.
- Блокирует только новые входящие подключения. Ответы на исходящие соединения проходят, поэтому сайты на «плохих» хостингах продолжают открываться через ваш сервер.
- TCP режется до conntrack, поэтому сканеры не забивают таблицу соединений.
- Новый список применяется одной атомарной операцией. Если список не скачался, оказался пустым или битым, остаётся последний рабочий.
- Не блокирует TCP-пакеты без SYN в состоянии NEW: такое правило рвёт живые соединения после переполнения или сброса conntrack.
