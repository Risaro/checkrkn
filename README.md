# checkrkn

Блокирует на сервере входящие подключения от подсетей сканеров: ГРЧЦ (СКИПА), Censys, Shodan и подобных.

## Установка

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Risaro/checkrkn/main/checkrkn.sh)
```

После установки список обновляется раз в сутки сам и применяется заново после перезагрузки.

## Команды

```bash
checkrkn status      # сколько адресов в блоке и сколько пакетов отброшено
checkrkn update      # обновить список сейчас
checkrkn uninstall   # удалить правила и службы
```

## Белый список

Адреса, которые нельзя блокировать ни при каких обстоятельствах (ваши серверы, мосты, панели), впишите в `/etc/checkrkn/allow.txt`, по одному IP или подсети на строку. Если в скачанном списке окажется такой адрес, список не применится, и останется последний рабочий.

## Чем отличается

- Работает через собственную таблицу nftables. UFW, iptables-persistent и правила Docker не трогает, поэтому безопасен на нодах с Docker.
- Отбрасывает пакеты до conntrack, поэтому сканеры не забивают таблицу соединений.
- Не задаёт вопросов при установке, его можно раскатывать сразу на много серверов.
- Применяет новый список одной атомарной операцией. Если список не скачался, оказался пустым или битым, остаётся последний рабочий.
- Отбрасывает подозрительно широкие сети (шире /16 для IPv4 и /32 для IPv6).
- Не блокирует TCP-пакеты без SYN в состоянии NEW: такое правило рвёт живые соединения после переполнения или сброса conntrack.

## Свой список

```bash
CHECKRKN_URL=https://example.com/list.txt checkrkn update
```

Чтобы список всегда брался оттуда, задайте `Environment=CHECKRKN_URL=...` в `checkrkn-update.service`.
